# Minimal Phaser 3 + Vite (JavaScript)

This is a minimal Phaser 3 project bootstrapped with Vite.

It includes:
- Phaser 3 dependency
- One scene (`MainScene`) in `src/main.js`
- Scene text: "Hello from Phaser 3 + Vite"
- A moving circle that tweens left and right continuously

## Run

1. Install dependencies:

```bash
npm install
```

2. Start development server:

```bash
npm run dev
```

3. Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```
